# Маркетинговая аналитика «Чё, как дизайн?»

Дашборд на живых данных из таблицы аналитики. Открывается в браузере, встраивается в Тильду, правится через ИИ (вайбкодинг) без сборки и серверов.

**Адрес:** https://neldnermaksim.github.io/dekhnich-analytics/

## Как это работает

```
Instagram, ChatPlace, Salebot, amoCRM, таблица таргетолога
        ↓ (каждый час, сами)
Таблица аналитики (Google Sheets) → лист «Факты»
        ↓ веб-приложение при таблице отдаёт сводные цифры (без Telegram ID и личных данных)
Этот дашборд (GitHub Pages) → встраивается в dekhnich.kz/analytics
```

- Таблица обновляется сама раз в час. Кнопка «Обновить» в шапке берёт свежие цифры из таблицы сразу.
- Цифры считаются так же, как в листах «Сводка» и «Динамика» таблицы, поэтому совпадают.
- План на месяц вносится в лист **«План»** таблицы (месяц, направление, канал, анкеты, валидные, продажи, сумма).
- Формат, сценарий и описание публикации берутся из рабочей таблицы (колонки «Формат», «Сценарий», «Описание») и видны в карточке публикации.

## Вкладки

| Вкладка | Что там |
|---|---|
| Сводка | 8 главных цифр, план на месяц, направления, воронка, доли продаж, топ-10 |
| Органика | Instagram: каналы, топ-10, все публикации с итогом, аккаунт по дням |
| Платный трафик | расход, показы, клики, входы, креативы, реклама по дням |
| Работа с базой | ТГ-канал, бот, почта, рассылки: каналы, топ-10, публикации |
| Динамика | по дням / неделям / месяцам; клик по дню показывает, что вышло и что принесло результат |
| План-факт | план на месяц по направлениям и каналам, сколько осталось, прогноз |
| Качество данных | что сейчас неточно (анкеты без источника, нет ссылок и т. п.) и когда обновлялись источники |

Во всех таблицах: сортировка по клику на заголовок, поиск, строка «Итого по видимым строкам», кнопка «Скачать CSV». Клик по названию публикации открывает карточку: ссылка на пост, сценарий, статистика Instagram, результат по дням.

Ссылкой можно делиться: адрес запоминает вкладку, период и фильтры (например `…/#organic?p=month`).

## Файлы

```
index.html       каркас страницы (шапка, вкладки, фильтры)
styles.css       внешний вид: цвета и размеры в начале файла
js/config.js     настройки: адрес данных, таблица, сколько строк в топе, период по умолчанию
js/data.js       загрузка и расчёты (суммы, конверсии, план, периоды)
js/app.js        вкладки и всё, что видно на экране
docs/data-api.md какие данные приходят из таблицы
AGENTS.md        правила для ИИ, который правит дашборд
```

Сборки нет: что лежит в репозитории, то и открывается.

## Как править через ИИ

1. Откройте репозиторий в Claude Code, Cursor или Codex (или правьте файл прямо на github.com, кнопка с карандашом).
2. Создайте ветку под свою правку (например `vika/top-creatives`).
3. Опишите ИИ, что нужно, и попросите сначала прочитать `AGENTS.md`.
4. Проверьте у себя: в папке проекта `python3 -m http.server 8000`, затем откройте http://localhost:8000.
5. Отправьте ветку и откройте Pull Request. После слияния в `main` сайт обновится сам за 1–2 минуты.

Примеры запросов к ИИ:
- «На вкладке Органика добавь в таблицу колонку Сохранения из Instagram».
- «В Сводке сделай топ-10 по умолчанию по анкетам, а не по сумме продаж».
- «Добавь пресет периода “Эта неделя”».

Если нужна новая цифра, которой нет в данных (см. `docs/data-api.md`), её сначала добавляют в скрипт таблицы. Это отдельная правка, напишите Максиму.

## Встроить в Тильду

На странице dekhnich.kz/analytics в блоке HTML (T123) замените адрес в iframe:

```html
<iframe src="https://neldnermaksim.github.io/dekhnich-analytics/" style="width:100%;height:100vh;border:0" loading="lazy"></iframe>
```
