# Данные дашборда

`GET <API_URL>` (адрес в `js/config.js`) возвращает JSON. Добавьте `&fresh=1`, чтобы таблица пересобрала ответ сразу (иначе ответ живёт в кеше до 10 минут и сбрасывается после каждого часового обновления).

В ответе только сводные цифры. Telegram ID, имена, телефоны и другие личные данные сюда не попадают.

## Верхний уровень

| Поле | Что это |
|---|---|
| `ok` | `true`, если всё хорошо; иначе есть `error` |
| `version` | версия формата (сейчас 1) |
| `generatedAt` | когда собран ответ (ISO) |
| `updated` | когда обновились сводки таблицы, «дд.мм.гггг чч:мм» |
| `timezone` | часовой пояс таблицы (`Asia/Almaty`) |
| `since` | с какой даты ведётся учёт публикаций |
| `today` | сегодня по времени таблицы, `yyyy-mm-dd` |
| `sheetUrl` | ссылка на таблицу аналитики |
| `directions` | направления: Органика, Платный, Работа с базой, Не определено |
| `channels` | пары `[направление, канал]` |
| `factColumns`, `facts` | факты по дням (ниже) |
| `units` | справочник публикаций и креативов (ниже) |
| `adsColumns`, `ads` | реклама по дням из таблицы таргетолога |
| `rates` | курс доллара по месяцам `{"2026-11": 435.88}` |
| `plan` | план из листа «План» |
| `igDailyColumns`, `igDaily` | аккаунт Instagram по дням |
| `statuses` | состояние источников: `{source, updated, status}` |

## facts

Каждая строка: один день × направление × канал × единица (как лист «Факты»).

`[date, direction, channel, unit, publications, reach, actions, registrations, forms, valid, sales, revenue, cost]`

- `date`: `yyyy-mm-dd`. Публикации и охват на день публикации, регистрации на день входа в бота, анкеты на день создания сделки, продажи и сумма на день оплаты, расход на день рекламы.
- `unit`: ключ из `units`. Пусто: общие расходы из листа «Затраты».
- В «Платном» для строки `ads:Таргет`: `reach` = показы, `actions` = клики, `registrations` = входы в бота, `cost` = расход в тенге.
- `revenue`, `cost` в тенге.

## units

Ключ → описание. Виды ключей:

- `o-rl-001`, `b-tc-001` …: публикации из рабочей таблицы или Instagram (код из Реестра).
- `utm:<креатив>`: креатив рекламы по метке amoCRM.
- `m:<source>|<medium>|<campaign>|<content>`: своя ссылка с метками.
- `ads:Таргет`: расход и показы рекламы без деления на креативы.
- `none:<направление>|<канал>`: сделки без источника.

Поля: `date` (дата публикации), `direction`, `channel`, `title`, `link`, `code`, `material`, `keyword`, `type`, `funnel`, `source` (откуда строка).

Если публикация есть в Instagram, добавляется `instagram`:
`kind` (Рилс, Пробник, Карусель, Пост, Сторис), `views`, `reach`, `likes`, `comments`, `saves`, `shares`, `interactions`, `follows`, `profileVisits`, `replies`, `frames`, `link`, `caption` (начало подписи), `publishedAt`, `updated`. Цифры за всё время публикации.

Если в рабочей таблице заполнены колонки, добавляется `details`: `format`, `scenario`, `description`.

## ads

`[date, spendUsd, impressions, clicks, entries]`: расход в долларах, показы, клики, входы в бота.

## plan

`{month: "2026-11", direction: "Все"|"Органика"|…, channel: ""|"Рилсы"|…, forms, valid, sales, revenue, comment}`. Пустая ячейка = `null` (плана нет).

## igDaily

`[date, followers, growth, accountReach]`: подписчики на день, прирост, охват аккаунта за сутки (сутки Meta, тихоокеанское время). Пусто = нет данных.
