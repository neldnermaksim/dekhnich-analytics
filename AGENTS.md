# Правила для ИИ, который правит этот дашборд

Прочитай целиком перед любой правкой. Как устроен весь проект (таблица аналитики, источники, связи, формулы, ограничения): `ИНСТРУКЦИЯ.md`. На вопросы команды «как это работает» отвечай по нему.

## Что это

Статический дашборд маркетинговой аналитики школы «Чё, как дизайн?». Хостинг: GitHub Pages, ветка `main`, корень репозитория. Встраивается iframe-ом в Тильду (dekhnich.kz/analytics). Данные приходят JSON-ом из веб-приложения Google Apps Script при таблице аналитики (`CONFIG.API_URL` в `js/config.js`).

## Жёсткие правила

1. **Без сборки и зависимостей.** Чистые HTML, CSS и JavaScript в браузере. Не добавляй npm, React, Vite, TypeScript, CDN-библиотеки и шрифты со сторонних сайтов. Страница должна открываться как есть.
2. **Не меняй `API_URL` и `SHEET_URL`** без просьбы владельца. Не добавляй ключи, токены и пароли в код: репозиторий публичный.
3. **Цифры должны совпадать с таблицей.** Суммы и доли считаются в `js/data.js` (`sum`, `derive`, `byPeriod`, `planFor`) так же, как листы «Сводка» и «Динамика». Если меняешь формулу, явно скажи об этом в описании правки.
4. **Конверсия больше 100% не показывается** (как в таблице): `derive()` возвращает `null`, на экране «—».
5. **Любой текст из данных выводи через `esc()`**, ссылки через `safeUrl()`. Никогда не вставляй значения из данных в HTML без экранирования.
6. **Тексты интерфейса на русском**, коротко и просто, без канцелярита и без длинных тире.
7. Не ломай то, что уже есть: итоги «по видимым строкам», CSV, сортировка, поиск, карточка публикации, адрес с вкладкой и периодом (`#tab?p=…`).

## Где что лежит

- `js/config.js`: настройки (адрес данных, размер топа, период по умолчанию).
- `js/data.js`: загрузка (`load`), выборка (`filter`), суммы (`sum`, `byDirChannel`, `byUnit`, `byPeriod`), план (`planFor`, `forecast`), форматирование (`fmt`, `dShort`…). Ничего про внешний вид.
- `js/app.js`: вкладки (`TABS`), фильтры, общие куски (`table`, `tableTools`, `topPanel`, `kpi`, `pill`), по функции на вкладку (`renderSummary`, `renderDirection`, `renderPaid`, `renderDynamics`, `renderPlan`, `renderQuality`), карточка (`openUnit`), события (`bindEvents`).
- `styles.css`: цвета в `:root`. Цвета направлений: органика зелёный, платный оранжевый, база фиолетовый, «не определено» красный. Не переназначай их.

## Как добавить…

- **Колонку в таблицу:** добавь объект в массив `cols` нужной вкладки: `{key, label, num: true, fmt: 'int'|'money'|'pct'|'pct0'|'usd', get: r => …}`. Для суммы в итоге поставь `sum: true`, для долей `noTotal: true` (или пересчитай в `derive`).
- **Вкладку:** добавь запись в `TABS` (id, label, filters, render) и функцию `renderX()`, которая возвращает HTML-строку.
- **Показатель из Instagram:** поля в `units[key].instagram` (см. `docs/data-api.md`).
- **Новые данные из таблицы:** их нет в JSON, пока не добавлены в скрипт таблицы (`buildDashData_` в Apps Script). Не придумывай поля: скажи владельцу, что нужно добавить на стороне таблицы.

## Проверка перед отправкой

1. `python3 -m http.server 8000` в корне, открой http://localhost:8000, пройди все вкладки.
2. Консоль браузера без ошибок.
3. На вкладке «Сводка» за «Этот месяц» цифры совпадают с листом «Сводка» таблицы за тот же период.
4. Узкий экран (360 px) не ломается.
5. Если менял `styles.css` или файлы в `js/`, увеличь номер `?v=` у этих файлов в `index.html` (например `?v=2` → `?v=3`), иначе браузеры до 10 минут будут показывать старую версию.
6. Правка в отдельной ветке, Pull Request с коротким описанием: что и зачем.
